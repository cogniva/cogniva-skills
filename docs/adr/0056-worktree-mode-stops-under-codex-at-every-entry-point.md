# Worktree mode stops under Codex at every entry point

**Provenance:** Suggested by agent

Worktree mode is not offered under Codex (not wanted at the time of this
decision): every skill that would start, integrate or clean up worktree-mode
work (plan-feature, execute-feature, quick-fix, cleanup-work, cleanup-allwork)
stops with one line when worktree mode is on and the Workflow tool is absent.
The parity record marks worktree mode `unsupported` for Codex rather than
leaving a path that works partway; the outcomes a Codex design would need,
should it ever be wanted, are recorded in the CrossHostParity plan's Stage 3.
