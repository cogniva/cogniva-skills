# A backlog item is a planned deferral

**Provenance:** Suggested by human

A backlog entry exists only with a stated reason not to do the work now (`because:` — blocked-on, sequenced-after, decision pending, or an explicit human "later"). Skill-initiated capture requires a concrete reason. A direct human capture is itself the deferral decision — an explicit "later" — so it is never blocked on a reason: one omitted is recorded as `because:human later`, and the agent offers once to make it specific. Reason-less real work is routed (Do now / Plan next) or dropped — never parked.
