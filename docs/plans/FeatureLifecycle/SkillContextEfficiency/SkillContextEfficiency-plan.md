> Task commit steps apply only under the active commits=task policy; otherwise leave changes unstaged and uncommitted.

**Goal:** Reduce recurring discovery context across the 25 skills, then fix four demonstrated sources of unnecessary invocation context while preserving behavior.

**Architecture:** Shorten descriptions first, retaining existing invocation metadata and essential triggers. Check discovery and glossary-first behavior in fresh sessions before implementing four bounded fixes: standalone backlog coverage, a shared commit-policy reference for quick-fix, conditional requirements-format reads, and glossary deduplication in place. Task 1 changes no parity rows: description shortening changes no listed mechanism, status, or existing evidence claim. Tasks 3–4 update `backlog`, `execute-feature`, `quick-fix`, `glossary`, and `project-records` for their actual loading changes. The console honors AGENTS.md parity obligations at before-integrate, adding minimal description/evidence notes if required rather than inventing mechanism or status changes. Preserve six manual-only metadata pairs, approved routing, runtime mechanisms, worktree stops, and journal asymmetries.

**Architecture profile:** UNDECLARED for the affected paths; no adoption or declaration is part of this work.
